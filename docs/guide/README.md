# User guide

Documentation for `MageOS_CustomerCustomAttributes`: custom customer and customer address attributes for Magento Open Source and
Mage-OS, built for Hyvä Theme and Hyvä Checkout.

| 4 | [Customer attributes](04-customer-attributes.md) | use attributes on registration, account, admin orders and in the checkout |
| 5 | [Address attributes](05-address-attributes.md) | use attributes in address forms and everywhere addresses are displayed |

| 8 | [API](08-api.md) | write and read values through REST |
| 9 | [Troubleshooting and FAQ](09-troubleshooting.md) | fix common problems |
